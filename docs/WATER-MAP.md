# แผนที่ระดับน้ำและรายงานใกล้บ้าน

เปิด `/{จังหวัด}/water-map` เช่น `/trang/water-map` หรือเลือกจากหน้าหลัก
เปลี่ยนจังหวัดแล้วขอบเขต รายชื่ออำเภอ/ตำบล สถานี และรายงานเปลี่ยนทันที ไม่ใช้ค่าจังหวัดเดิมระหว่างโหลด

## แหล่งข้อมูลและข้อจำกัด

- สถานี: [ThaiWater สสน.](https://www.thaiwater.net/), endpoint สาธารณะ `https://api-v3.thaiwater.net/api/v1/thaiwater30/public/waterlevel_load` ตรวจรูปแบบจากต้นทางเมื่อ 3 ตุลาคม 2026 ไม่ต้องใช้ API key ในขณะตรวจสอบ แต่ endpoint อาจเปลี่ยนและไม่มีการรับประกัน SLA
- ใช้รหัสจังหวัดใน `geocode.province_code` ไม่เทียบชื่อจังหวัดแบบคลุมเครือ สีตาม `situation_level` ของ ThaiWater แยกจากความลึกน้ำท่วมที่ประชาชนรายงาน
- ม. รทก. คือระดับอ้างอิงน้ำทะเลปานกลาง ไม่ใช่ความลึกน้ำท่วมบนถนน เปรียบเทียบตลิ่งเมื่อมี `waterlevel_msl` และ `station.min_bank` เท่านั้น ไม่เอาหน่วยความลึกมาเปรียบเทียบกับระดับทะเล
- ดึงครั้งเดียวทั่วประเทศแล้วแคชร่วม 5 นาที มี lock ป้องกันเรียกซ้ำพร้อมกัน timeout 15 วินาทีและพัก 60 วินาทีเมื่อผิดพลาด ข้อมูลแคชสำรองไม่เกิน 1 ชั่วโมงพร้อมข้อความข้อมูลเก่า; เวลาวัดเกิน 6 ชั่วโมงเป็นสีเทาและไม่รวมสรุปล้นตลิ่งปัจจุบัน
- ไม่มีข้อมูล / ติดต่อไม่ได้ แสดงว่าไม่พร้อม ไม่ปลอมเป็น 0 หรือปลอดภัย หน้าเว็บโหลดสถานีแบบแยกคำขอ ไม่ต้องรอ API เพื่อแสดงหน้า
- รายงาน: เฉพาะรายงานที่เผยแพร่ ยังไม่หมดอายุ อัปเดตไม่เกิน 12 ชั่วโมง อยู่ในจังหวัด และระดับตั้งแต่ 2 ไม่รวมรายงานน้ำแห้ง ไม่มีชื่อ เบอร์ รูป โน้ต หรือรายละเอียดคำขอความช่วยเหลือใน endpoint นี้
- GPS คำนวณรัศมี 3 กม. ในเบราว์เซอร์ ไม่ส่งพิกัดเข้า API ของแอป ไม่ขอ GPS จนผู้ใช้กดปุ่มเอง แผนที่ใช้ tile OpenStreetMap จึงยังมีการโหลดภาพแผนที่จากผู้ให้บริการภายนอก
- พิกัดที่อยู่นอกจังหวัดหรือ GPS คลาดเคลื่อนมากกว่า 1 กม. จะไม่สรุปพื้นที่ที่ไม่ตรงกัน ให้เปลี่ยนจังหวัดหรือเลือกพื้นที่แทน
- เลือกตำบล: กรองด้วยรหัสตำบลที่รายงานถูกผูกไว้ หากมีรายงานที่ไม่ระบุตำบลแสดงข้อจำกัด ไม่ใช้พิกัดกึ่งกลางตำบลแทนบ้านของผู้ใช้
- รายงานมากกว่า 3000 รายการแสดงคำเตือนข้อมูลอาจไม่ครบ ไม่พบรายงานไม่เท่ากับไม่มีน้ำท่วม และระดับน้ำสถานีไม่ใช่การรับรองความปลอดภัย
- การเชื่อมนี้ใช้เพื่อแสดงข้อมูลสาธารณะเท่านั้น ไม่เพิ่มเกณฑ์เตือนอัตโนมัติหรือเขียนทับสถานี/ขอบเขตปฏิบัติงานเดิม ให้หน่วยงานตรวจข้อมูลและสิทธิ์ใช้บริการก่อนเปิดใช้งานจริง

## เครดิตข้อมูลประกอบและภาพ

- ขอบเขตอ้างอิง 77 จังหวัด: geoBoundaries `THA-ADM1-36821470`, ปีข้อมูล 2017, OpenStreetMap/Wambacher, ใบอนุญาต [ODbL 1.0](https://opendatacommons.org/licenses/odbl/1-0/), [ข้อมูลและ metadata](https://www.geoboundaries.org/api/current/gbOpen/THA/ADM1/). เก็บสำเนาต้นฉบับ simplified GeoJSON ไม่แก้ geometry ใน `resources/data/thailand-provinces.geojson`; source pinned ที่ commit `9469f09`. มีเฉพาะจังหวัด ไม่อ้างว่ามีเส้นขอบตำบลครบ ใช้เป็นแผนที่อ้างอิง ไม่ใช่ขอบเขตทางกฎหมาย
- รายชื่ออำเภอ/ตำบลและพิกัดอ้างอิง: [kongvut/thai-province-data](https://github.com/kongvut/thai-province-data), API latest v3 snapshot ดาวน์โหลด 3 ตุลาคม 2026. MIT, เก็บใบอนุญาตครบใน `resources/data/area-data-LICENSE.txt`. บางพื้นที่ไม่มีพิกัด จึงไม่สร้างพิกัดทดแทน ข้อมูลนี้ใช้เฉพาะ selector ไม่เพิ่ม/แก้พื้นที่ปฏิบัติงานในฐานข้อมูล
- ภาพประกอบใหม่: สร้างด้วยเครื่องมือ imagegen แบบ built-in, ไฟล์ `public/images/water-community-banner.png` ไม่ใช่ภาพสถานการณ์จริง ไม่ใช่แผนที่หรือผลพยากรณ์
- Prompt: "A refined modern 3D paper-and-clay miniature Thai riverside neighborhood, tropical homes beside a winding turquoise river, a water-level measuring post and map-location motif; wide panoramic composition with quiet left negative space; reassuring preparedness mood; pale teal, mint, cream and coral; no text, logos, watermark, real geography or evidence of flooding."

## ขึ้นโฮสต์

รวม `resources/data` และภาพใหม่ใน ZIP รุ่นใหม่ด้วย ใช้ HTTPS เพื่อให้ GPS ทำงานได้ (localhost เป็นข้อยกเว้นของเบราว์เซอร์)
โฮสต์ต้องออก HTTPS ไป ThaiWater ได้และมี certificate store ที่ตรวจ TLS ได้ ไม่ปิด verification เมื่อ provider ล่ม
หน้านี้ดึงสถานีตามการเปิดดูและแคช ไม่ต้องรัน scheduler เพื่อแสดงสถานี แต่ฟังก์ชันเตือนภัยและคิวส่วนอื่นยังต้องตั้ง Cron ตามคู่มือติดตั้ง
