# FloodThai 1.1.0 — พื้นที่ของฉันและข้อมูลที่ตรวจสอบได้

## สิ่งที่เพิ่ม

- เมนู **พื้นที่ของฉัน** (`/my-area`) บันทึกจังหวัด อำเภอ/เขต ตำบล/แขวงได้ 5 พื้นที่ในเบราว์เซอร์ เปิดครั้งต่อไปกลับมาพื้นที่ล่าสุดได้ ไม่ต้องสมัคร ไม่เก็บพิกัดส่วนตัวบนเซิร์ฟเวอร์ ล้างข้อมูลที่บันทึกได้
- หน้า **ภาพรวมและกราฟ** (`/{province}/insights`) บนคอมพิวเตอร์แสดงหลายคอลัมน์ มือถือเรียงการ์ด เลือกจังหวัดแล้วเปลี่ยนข้อมูลทันที ไม่แสดงคำตอบเก่าข้ามจังหวัด มีตารางอ่านค่ากราฟสำหรับทุกคน
- กราฟฝน 24 ชั่วโมงข้างหน้าจาก Open-Meteo บริเวณตัวเมืองจังหวัด ระบุช่วงพยากรณ์และเวลาที่ดึง ไม่อ้างเป็นพยากรณ์เฉพาะตำบล
- กราฟระดับน้ำย้อนหลัง 72 ชั่วโมงและเส้นตลิ่ง เมื่อแหล่งข้อมูลมีค่าตลิ่งหน่วยเดียวกัน แสดงค่าสุดท้ายที่ตรวจวัดในแต่ละชั่วโมง ข้อมูลที่ขาดเว้นช่องว่าง ไม่มีเส้นเชื่อมข้ามช่วงที่ไม่มีข้อมูล
- ประวัติ ThaiWater เริ่มสะสมหลังอัปเดตนี้ ไม่สร้างประวัติย้อนหลังขึ้นเอง งาน Cron เก็บทุก 10 นาทีจากแคชข้อมูลระดับประเทศร่วมกัน เก็บ 14 วัน ไม่เขียนทับสถานีที่เจ้าหน้าที่ตั้งไว้
- กราฟรายงานในพื้นที่ เฉพาะข้อมูลที่ยังเผยแพร่ อัปเดตใน 24 ชั่วโมง ไม่หมดอายุ แยกตามเวลาอัปเดต (ไม่ใช่จำนวนเหตุใหม่) เลือกอำเภอ/ตำบลได้ตามรหัสจริง ไม่เปิดเผยชื่อ เบอร์โทร หมายเหตุ หรือพิกัดรายงานผ่านข้อมูลกราฟ
- หน้า **ความสดของข้อมูล** (`/{province}/data-status` และ `/admin/data-health`) แสดงเวลาเชื่อมต่อล่าสุด เวลาตรวจวัด อายุข้อมูล และการเชื่อมต่อที่ล้มเหลว แยก ThaiWater/Open-Meteo/RainViewer กดตรวจแต่ละต้นทางได้
- แจ้งผู้ดูแลที่ศูนย์สั่งการเมื่อข้อมูลเก่าหรือเชื่อมต่อไม่ได้ ไม่สร้างเหตุเตือนภัยน้ำท่วมจากปัญหาต้นทาง
- คำสั่งอัปเดต `flood:upgrade` เพิ่มเฉพาะตารางที่ยังไม่มีและล้างไฟล์คอมไพล์ ไม่รีเซ็ตฐานข้อมูล ไม่เปลี่ยน APP_KEY

## อัปเดตจาก 1.0.0 บน Plesk

1. สำรองฐานข้อมูล `.env` และ `storage` ของเว็บไซต์เดิม ตรวจว่าไฟล์สำรองอยู่นอก public และกู้คืนได้
2. แตก ZIP รุ่น 1.1.0 ทับโฟลเดอร์ `floodthai` เดิม **ไม่ลบโฟลเดอร์เดิมก่อน** แพ็กเกจไม่มี `.env` จริง ไม่มีฐานข้อมูลจริง ไม่มีรูปผู้ใช้ และไม่มี setup-key ของเว็บไซต์เดิม
3. ใน Scheduled Tasks สร้างงาน **ชั่วคราว** ชนิด Run a PHP script เลือก PHP 8.3+ และไฟล์ `water-map.thereal-programmers.com/floodthai/artisan` ใส่ Arguments `flood:upgrade` แล้ว Run Now ตรวจผลว่าสำเร็จ จากนั้นเอางานชั่วคราวนี้ออก
4. คง Cron ทุกนาที `artisan flood:cron` ของเดิมไว้ งานสะสมประวัติ ThaiWater ถูกเพิ่มในตารางงานอัตโนมัติแล้ว ไม่ต้องสร้าง Cron ซ้ำ
5. เปิด `/{province}/insights`, `/{province}/data-status` และ `/admin/data-health` กดตรวจต้นทาง ทดสอบเลือกจังหวัด/อำเภอ/ตำบล และดูเวลาดึงกับเวลาตรวจวัด กราฟประวัติจะมีจุดเพิ่มเมื่อสถานีส่งข้อมูลรอบใหม่

ห้ามเปิด `install.php` ติดตั้งซ้ำบนข้อมูลเดิม ห้ามใช้ `migrate:fresh` หรือเปลี่ยน APP_KEY ขณะอัปเดต หากฐานข้อมูลอัปเดตไม่ผ่าน ให้หยุดและตรวจผลงานก่อนเปิดฟังก์ชันใหม่

## ข้อจำกัดที่แสดงให้ผู้ใช้เห็น

- ไม่พบรายงาน **ไม่ได้แปลว่าไม่มีน้ำท่วม** โดยเฉพาะรายงานที่เจ้าหน้าที่ไม่ได้ระบุรหัสพื้นที่ จะไม่ถูกนับเป็นตำบลที่เดาเอง
- การเลือกตำบลกรองเฉพาะรายงาน กราฟฝนยังเป็นบริเวณตัวเมือง และรายการสถานียังเป็นทั้งจังหวัด มีป้ายกำกับชัดเจน
- ระดับน้ำสถานีเป็นระดับน้ำลำน้ำ ไม่ใช่ความลึกน้ำท่วมหน้าบ้าน สถานีที่ใช้ระดับอ้างอิงท้องถิ่นไม่เทียบตลิ่งในหน่วย รทก.
- ความสดของต้นทางไม่ยืนยันความปลอดภัยพื้นที่ การแจ้งเหตุฉุกเฉินให้ใช้ช่องทางศูนย์/สายด่วนที่จังหวัดประกาศ
