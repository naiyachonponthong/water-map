# แผนที่สถานการณ์น้ำฉบับรวม

หน้า `/{province}/map` แสดงระดับน้ำสถานี ThaiWater ในจังหวัดเดียวกับรายงานประชาชน
พร้อมจุดเสี่ยง สถานีของหน่วยงาน ศูนย์พักพิง และกล้อง CCTV ของจังหวัดนั้น
ขอบเขตจังหวัดอ้างอิงและพื้นที่ด้านนอกจางลงใช้ชุดเดียวกับหน้าแผนที่ระดับน้ำ
เปลี่ยนจังหวัดจากตัวเลือกแล้วเปิดหน้าใหม่ของจังหวัดนั้น ไม่เก็บข้อมูลจังหวัดเดิมมาปะปน

ตัวเลขวงกลมเป็นระดับน้ำสถานีตามหน่วยที่ต้นทางระบุ ไม่ใช่ความลึกน้ำที่ท่วมบ้าน
จุดรายงานประชาชนใช้เกณฑ์น้ำแห้ง / เข่า / เอว / อก / เกินอก / มิดหัวคนละชุดกับ ThaiWater
คลิกรายการหรือสถานีเพื่อดูค่าเทียบตลิ่ง แนวโน้มจากค่าก่อนหน้า หน่วยงานและเวลาวัด
เมื่อโหลดไม่ได้แสดง `—` ไม่แสดงศูนย์หรือสถานะปลอดภัย ข้อมูลเก่าแสดงสีเทา
แคช ThaiWater ร่วมกับหน้า `/water-map`; ดูข้อจำกัดและเครดิตแหล่งข้อมูลใน `WATER-MAP.md`

## เครดิตผู้จัดทำ

เครดิตผู้จัดทำ **Naiyachon ponthong** อยู่ในแม่แบบกลางของหน้าสาธารณะ หลังบ้าน และล็อกอิน
มี metadata author และเครดิตที่มุมแผนที่ ไม่มีตัวเลือกแก้หรือซ่อนในหน้าตั้งค่าหลังบ้าน
`php artisan flood:credits-check` ตรวจแบบอ่านอย่างเดียว
ตัวสร้าง ZIP ตรวจไฟล์เครดิตก่อนคัดลอกและก่อนบีบอัด ถ้าเครดิตหายจะไม่สร้างแพ็กเกจ
`NOTICE.md` ถูกรวมใน ZIP เสมอ ไม่ลบเครดิตของไลบรารีหรือผู้ให้บริการข้อมูลภายนอก

ข้อจำกัด: ผู้ที่แก้ซอร์สหรือเซิร์ฟเวอร์ได้ยังเปลี่ยนหรือลบเครดิตได้
ไม่มีระบบโทรกลับเซิร์ฟเวอร์ผู้จัดทำ ไม่มีการส่งข้อมูลผู้ใช้เพื่อบังคับเครดิต
และไม่มีการหยุดระบบช่วยเหลือหากเครดิตถูกแก้ ไม่รับประกันการป้องกันการลบทั้งหมด
