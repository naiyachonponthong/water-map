# ผลตรวจ FloodThai v1.0.0

ตรวจ 4 ต.ค. 2026 บน Windows, PHP 8.3.35, Laravel 13.34.0

- PHPUnit: 152 tests / 1304 assertions ผ่าน ไม่มี PHPUnit notices (SQLite ในหน่วยความจำ ไม่แตะฐานข้อมูลใช้งาน)
- Frontend: 21 tests ผ่าน รวมเปลี่ยนจังหวัด/ผลตอบกลับล่าช้า แผนที่สถานี ใกล้บ้าน และคู่มือ
- Compile + PHP lint: 164 Blade views ผ่าน
- ผู้ช่วยตั้งค่า 5 ขั้น: ตรวจภาพที่ 1440px และ 390px ไม่มีหน้าล้นแนวนอน ใช้ข้อมูลทดสอบเท่านั้น
- ZIP: production dependencies 92 packages ไม่รวม .env, ฐานข้อมูล, log, รหัสติดตั้ง หรือรูปอัปโหลด
- ติดตั้งใหม่จาก ZIP: 28 checks ผ่าน บน MariaDB 10.4.32 ชั่วคราวพอร์ต 3308 แยกจากระบบเดิม
- ตรวจยืนยันเจ้าของ/CSRF, เก็บรหัสผู้ดูแลแบบ hash, key ไม่เปลี่ยน, debug ปิด, installer ล็อก, 77 จังหวัดและผู้ดูแลเฉพาะเครื่อง
- ตรวจหน้าเว็บประชาชน 11 URLs และ Cron scheduler/queue มี heartbeat จริง

ลบฐานข้อมูลและผู้ใช้ทดสอบหลังจบ ไม่แก้ฐานข้อมูลหรือเว็บไซต์จริง
การตรวจนี้ไม่ใช่การทดสอบโหลด ไม่รับรองข้อมูล API ภายนอก และไม่แทนการทดลองบนโฮสต์ของผู้รับแต่ละราย
