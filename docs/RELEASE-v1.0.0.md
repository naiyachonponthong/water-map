# FloodThai v1.0.0 — ชุดติดตั้งสำหรับแจกจ่าย

ดาวน์โหลด **floodthai-v1.0.0.zip** พร้อม **floodthai-v1.0.0.zip.sha256** จาก Assets ด้านล่าง
ZIP นี้มี dependencies สำหรับ production ครบ ไม่ต้องใช้ Composer บนโฮสต์
**Source code (zip/tar.gz) ไม่ใช่ชุดติดตั้งพร้อมใช้งาน**

## สิ่งที่เพิ่ม

- ผู้ช่วย `/admin/setup` 5 ขั้น: จังหวัด, หน่วยงาน/สายด่วน, เจ้าหน้าที่/ขอบเขต, โฮสต์/Cron, ทดลองก่อนเปิดศูนย์
- แยกข้อมูลและผลการตรวจตามจังหวัด ป้องกันบันทึกผิดจังหวัดเมื่อมีอีกแท็บสลับพื้นที่
- คู่มือ Plesk / cPanel / DirectAdmin และ Cron แบบ Run a PHP script สำหรับ Plesk
- ข้อกำหนดใช้/แก้ไข/แจกต่อฟรี โดยคงเครดิต Naiyachon ponthong ตาม LICENSE.md
- แก้หน้า My Team, หน้าศูนย์พักพิง, เบอร์ผู้เสนอจุดเสี่ยง และการอัปเดตพยากรณ์ซ้ำบน SQLite

## ข้อกำหนด

PHP 8.3 ขึ้นไป, MySQL/MariaDB, HTTPS, Document Root ชี้ `public`, Cron ทุกนาทีและ PHP CLI รองรับ `proc_open`
ใช้ฐานข้อมูลว่างแยกสำหรับติดตั้งใหม่ อ่าน START-HERE.md ใน ZIP
หลังติดตั้งให้ตั้ง 2FA และใช้ผู้ช่วย 5 ขั้น ระบบยังไม่เปิดรับเหตุเอง

## เว็บไซต์เดิม

สำรองฐานข้อมูล `.env` และไฟล์อัปโหลดก่อนอัปเดต เก็บ APP_KEY เดิม ดู docs/DEPLOY.md
ห้ามใช้ตัวติดตั้งใหม่หรือ migrate:fresh กับข้อมูลเดิม ไม่อัปเดตเว็บไซต์จริงอัตโนมัติเมื่อเผยแพร่ release

ชุดทดสอบอัตโนมัติและทดสอบตัวติดตั้งผ่าน ไม่รับรองความพร้อมของ API ภายนอก สถานการณ์จริง หรือทุกประเภทโฮสต์
ใช้ฟรีไม่รวมค่าโฮสต์ ค่า API และการสนับสนุน; dependencies และข้อมูลภายนอกมีข้อกำหนดของเจ้าของเดิม
