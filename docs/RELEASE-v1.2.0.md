# FloodThai 1.2.0 — เรดาร์อัตโนมัติและพยากรณ์ตรงพื้นที่

## สิ่งที่เปลี่ยน

- เรดาร์เริ่มเล่นอัตโนมัติเมื่อแผงเรดาร์เปิดอยู่ และมีอย่างน้อยสองภาพ
- รอภาพโหลดก่อนเปลี่ยนเฟรม พักเมื่อซ่อนแท็บหรือเลื่อนแผนที่ และกลับมาเล่นตามสถานะเดิม
- กดหยุดหรือเลื่อนแถบเวลาเพื่อดูภาพนิ่งได้ ผู้ตั้งค่าลดการเคลื่อนไหวสามารถกดเล่นเอง
- เลือกอำเภอ / เขต และตำบล / แขวงเพื่อใช้พิกัดอ้างอิงในพื้นที่ แคชแยกตามพิกัด
- ใช้ Open-Meteo Best Match พร้อมเลือกจุดบนบก และแสดงชื่อพื้นที่พยากรณ์ให้ชัดเจน
- เพิ่มช่วงเวลาที่คาดว่าฝนตก ฝนสูงสุดรายชั่วโมง และจำนวนชั่วโมงที่คาดว่ามีฝน
- หน้าอากาศอัปเดตอัตโนมัติทุก 15 นาทีเมื่อเปิดดูอยู่
- สภาพอากาศปัจจุบันจากแบบจำลองที่เก่ากว่า 45 นาทีจะไม่แสดงเป็นค่าปัจจุบัน และเรดาร์กรองภาพเก่าเกินสามชั่วโมง / ภาพเวลาอนาคต

พยากรณ์เป็นค่าคาดการณ์บริเวณพิกัดอ้างอิง ไม่ใช่ค่าเฉลี่ยทั้งตำบล และการเลือกพื้นที่ไม่ได้เปลี่ยนความละเอียดของแบบจำลองต้นทาง โอกาสฝนไม่ใช่เปอร์เซ็นต์ความแม่นยำ ภาพเรดาร์ว่างอาจเป็นพื้นที่ไม่มีข้อมูลครอบคลุม

เอกสารต้นทาง: [Open-Meteo](https://open-meteo.com/en/docs) และ [RainViewer](https://www.rainviewer.com/api/weather-maps-api.html)

## อัปเดตเว็บไซต์เดิม

1. สำรองฐานข้อมูล `.env` และโฟลเดอร์ `storage`
2. อัปโหลด `floodthai-v1.2.0.zip` แล้วแตกทับโฟลเดอร์ `floodthai` เดิม เลือก **Replace existing files**
3. รัน `flood:upgrade` หนึ่งครั้งเพื่ออัปเดตตามสถานะระบบและล้างแคช รุ่นนี้ไม่มี migration ใหม่
4. เปิดหน้าอากาศแล้วกด Ctrl+F5

สำหรับเว็บไซต์ water-map ใน Plesk ใช้ Scheduled Task ชั่วคราวชนิด **Run a PHP script**, Script path `water-map.thereal-programmers.com/floodthai/artisan`, Arguments `flood:upgrade`, PHP 8.3 ขึ้นไป แล้วกด **Run Now** งานประจำเดิมใช้ `flood:cron` ต่อไป

ห้ามใช้ตัวติดตั้งใหม่กับเว็บไซต์ที่ใช้งานอยู่
