# FloodThai 1.1.1 — ภาพประกอบหน้า “พื้นที่ของฉัน”

รุ่นนี้เพิ่มภาพประกอบใหม่ให้แบนเนอร์หน้า `พื้นที่ของฉัน` เพื่อให้หน้าแรกดูอบอุ่นและทันสมัยขึ้น พร้อมปรับชั้นสีให้ข้อความอ่านง่ายบนภาพทั้งหน้าจอใหญ่และมือถือ

## อัปเดตเว็บไซต์เดิม

1. สำรองไฟล์ `.env` และโฟลเดอร์ `storage` ของเว็บไซต์จริงไว้ก่อน
2. ดาวน์โหลด `floodthai-v1.1.1.zip` จากหน้า Releases
3. แตก ZIP ทับโฟลเดอร์ `floodthai` เดิม โดยเลือก **Replace existing files**
4. ไม่ต้องเปิดตัวติดตั้งใหม่ และไม่ต้องรัน migration เพราะรุ่นนี้ไม่มีการเปลี่ยนฐานข้อมูล
5. หากยังเห็นหน้าเก่า ให้ล้าง view cache ด้วยคำสั่ง `php artisan view:clear` ผ่าน Scheduled Task ชั่วคราว หรือกด Ctrl+F5

ไฟล์ภาพอยู่ที่ `public/images/my-area-hero.png` และ CSS จะโหลดด้วยเวลาแก้ไขไฟล์เพื่อช่วยลดปัญหาแคชค้าง
